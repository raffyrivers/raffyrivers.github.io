### Introduction 
UI frameworks offer developers a set of tools they may use to format their web application. For instance, Bootstrap provides developers with pre written css files allowing them to format a website without ever editing a css file. Bootstrap is one of the more popular UI frameworks and there are many more available with different capabilities and use cases.

### Whats the Point?
For some, UI frameworks and libraries may add an unnecessary layer of obfuscation. Certain webapps may require more hands on implementations, like when a developer wants their webapp to look a certain way or perform particular functions that frameworks don't provide. This case would require a developer to have clear knowledge of what they are implementing. 

There are many reasons why developers should use UI frameworks and any software framework. Libraries and frameworks allow developers to share their problems with other developers and create solutions. Since multiple developers are using the same framework, when one comes across an issue they can ask others for help and provide a solution to people who have that problem in the future. Frameworks act as a "black box" meaning developers don't need to understand how it works in order to use it. This makes frameworks easier to pick up for beginners. They also, in most cases, save a lot of time and allow developers to produce decent applications without having to rewrite code.

### Conclusion
In the end, UI frameworks are useful tools with many applications. There exist many frameworks that can fit almost any developer's needs. Ultimately, it is up to the developer to decide which framework to use, or even use a one. They can make a programmer's life much easier and allows programmers to not have to write code that is already written. There are always new frameworks being made with different capabilities and standards. They can be cumbersome to learn but having them as a tool is incredibly useful.
