### Where Recreational Programming Takes Me 

A person could take up programming recreationally to, perform better at work, expand their skill set, or out of simple curiosity. For example, someone who 
wants to learn to create games from scratch would need to practice by programming for fun. As they keep praticing and improving themselves they can become
capable of rendering graphics, creating intracit game systems, learn to use a build system, and many others skills that can be used to achieve this goal. These
skills will help with different goals in the future, letting them achieve these goals quicker than when they were starting out.
